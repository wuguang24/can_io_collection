================================================================================
1  通讯简介
================================================================================

1.1  适用范围

  本文描述 EXP 下料口 IO 主控（下称「主机」）与 WCS 之间的 UDP 通讯。
  帧头、序号、长度、异或校验、应答规则（请求 0x14xx → 应答 0x94xx）与
  《交叉带分拣系统通讯协议》1.2 节一致；数据区全部小端。

  本文覆盖：
    · 交叉带第 5 章中本固件已实现的业务命令（0x1402～0x1406、0x140B、0x1413 等）
    · V5 通用配置扩展（0x1422～0x1432）

  主机与从站板之间的 CAN 配置/状态不在 WCS 报文内，见第 6 章（理解 1402 来源）。

1.2  系统框图

  ┌────────┐  UDP   ┌──────────────┐  CAN   ┌────────────┐
  │  WCS   │◄──────►│ 下料口主机    │◄──────►│ 从站板 ×N   │
  │ 上位机  │        │ (EXP 主控)    │        │ 拨码站号≥2  │
  └────────┘        └──────────────┘        └────────────┘

1.3  帧公共区 cmd[11]

  各命令数据区均以 11 字节帧公共头开始（下称 cmd[11]），含义同交叉带 1.2：
    帧头 0xAAAA | 帧序号(4) | 帧长度(2) | 校验(1) | 帧类型(2)
  下文 typedef 中 uint8 cmd[11] 均指该公共头，不再重复说明。

1.4  主机就绪

  主机认为「配置就绪」须同时成功接收：
    0x1423（拓扑）+ 0x1424（格口地址范围）+ 0x1425（滤波时间）+ 0x1426（脚位绑定）
  就绪后向从站分发 PIN / TIME / FUNC，并开始周期上报 0x1402。
  未就绪时每秒上报 0x1429；就绪后若从站异常上报 0x142A。

  0x1428（灯效）、0x142F（扩展上报）、0x142D（Flash 固化）不参与就绪判定。

2  术语与对象模型
================================================================================

  下列中文术语在全文统一使用；结构体字段保留英文，与固件一致。

  名词              英文字段（常见）     含义
  ─────────────────────────────────────────────────────────────────
  格口地址          port_no / port_io    WCS 使用的业务口编号，全机唯一；
                                         0x1402/0x1405 等均用此地址
  从站站号          station              从板拨码站号，≥2；CAN 目标地址
  本地口            local_port           单块从板内格口槽位 0～7
  物理脚            pin                  从板 DI/DO 编号 0～7
  格口地址范围      ip_offset_start/end  本主机负责的格口地址闭区间（1424）
  拓扑组            group                1423 中的从站集合，用于 FUNC 打包约定
  卡包组号          block_group          1423 拓扑属性，通常 1 或 2
  夹件连带列表      jam_fanout           某口夹件触发时额外带入 1402 的卡包组地址
  逻辑通道          CH0～CH5             主机内部灯效通道（非物理脚号）
  输入角色          in_func              锁格/打印/满包/半满/夹件/门磁等
  输出绑定          out_func             物理 OUT 脚承接哪路逻辑通道

  对象关系（配置期）：
    WCS ──1423/24/25/26──► 主机运行表 ──CAN:FUNC/TIME/PIN──► 从站
                │                              │
           可选 1428 灯效                   COS 状态回传
           可选 142F 扩展

3.1  可直接按交叉带对接（格式一致或子集）

  帧类型    交叉带章节    本固件说明
  ─────────────────────────────────────────────────────────────────
  0x1402    5.1           每 500ms 上报；四组 close/full/block/door；
                          无 Pause 组；内容不变也发送（在线心跳）
  0x1403    5.2           建链上线；主机主动发，WCS 可不应答
  0x1404    5.3           打印键边沿触发上报（非长按重复）
  0x1405    5.4           仅实现 close_cmd=0关格、1开格
  0x1406    5.5           清空下料口
  0x140B    5.10          版本号
  0x1413    5.17          从板 CAN 异常，约 5s，有故障才发
  0x1422    5.27          屏幕数据转发
  0x1423    5.28          拓扑（V5 语义扩展，见 5.2）
  0x1424    5.28          格口地址偏移范围
  0x1425    5.30          五类滤波时间（固定 5 项，见 5.4）
  0x1429    5.33          V5 增加 1 字节 missing_flags
  0x142B    5.35          急停转发
  0x142C    5.36          子模块版本校验

3.2  V5 扩展或语义变更（须按本文实现）

  帧类型    说明
  ─────────────────────────────────────────────────────────────────
  0x1426    物理脚绑定（交叉带无；V5 上线必须）
  0x1427    交叉带为从机数量；V5 仅更新灯效矩阵，从机数并入 1423
  0x1428    交叉带为 frequency/keeptime；V5 为组合规则或矩阵（见 5.6）
  0x142A    交叉带为按钮触发打印；V5 为从站 PIN/配置失败诊断
  0x142D    本地 Flash 模板/异类固化
  0x142E    运行中修改夹件连带列表
  0x142F    扩展上报组 + 跨站公共 OUT
  0x1430    拓扑从站就位（仅联调；运行期在线看 0x1402）
  0x1431    触发 CAN 站号自学习
  0x1432    站号学习完成结果

3.3  交叉带有、本固件未实现（上位机勿依赖）

  0x1402 Pause 组；0x1407～0x140A；0x1411/0x1414～0x1421；0x1405 close_cmd 2～13


================================================================================
4  业务命令（交叉带兼容）
================================================================================

4.1  下料口按键实时状态（0x1402）

（1）发送时间
  主机每 500ms 发送一次；发送方为主机。
  即使各组地址列表与上周期相同也发送，供 WCS 判断下料口在线。
  从站 COS 超时的格口不参与组包（视为离线）。

（2）发送帧命令：0x1402

（3）数据格式（单帧，数据区 ≤256 字节）

typedef struct
{
    uint8  cmd[11];
    uint16 close_addr_num;
    uint16 close_addr[close_addr_num];
    uint16 full_addr_num;
    uint16 full_addr[full_addr_num];
    uint16 block_addr_num;
    uint16 block_addr[block_addr_num];
    uint16 door_addr_num;
    uint16 door_addr[door_addr_num];
    /* 以下可选扩展组，由 0x142F 或 0x1428.report_flags 开启 */
    uint16 half_addr_num;          /* 半满 */
    uint16 half_addr[half_addr_num];
    uint16 full_tier1_addr_num;    /* 满包档 1 */
    uint16 full_tier1_addr[full_tier1_addr_num];
    uint16 full_tier2_addr_num;    /* 满包档 2 */
    uint16 full_tier2_addr[full_tier2_addr_num];
} sIOCtrl2WCS_PortState_Data;

变量类型    变量名              含义
uint8       cmd[11]             帧公共头
uint16      close_addr_num      关格/远程锁格口数量
uint16      close_addr[]        格口地址（0x1405 关格或锁格有效）
uint16      full_addr_num       满包有效格口数量
uint16      full_addr[]         满包格口地址
uint16      block_addr_num      卡包/夹件有效数量（含连带地址）
uint16      block_addr[]        卡包格口地址（本口 + jam_fanout 列表）
uint16      door_addr_num       门关上格口数量
uint16      door_addr[]         门磁有效格口地址

  说明：
    · 无 Pause 组（交叉带 5.1 中的 Pause 本固件不上报）。
    · block 组含夹件触发口及其 1426/142E 配置的连带格口地址。
    · 扩展组顺序：半满 → 满包档1 → 满包档2；未开启时不存在对应 count 字段。

（3b）分片格式（数据区 >256 字节时，同周期连发多帧 0x1402）

typedef struct
{
    uint8  cmd[11];
    uint16 magic;           /* 固定 0xFFFE */
    uint8  seg_total;       /* 本周期总片数 */
    uint8  seg_index;       /* 当前片序号，0 起 */
    uint16 body_len;        /* 重组后完整数据区长度 */
    uint16 body_crc;        /* 完整数据区 CRC16-CCITT(初值0xFFFF, 多项式0x1021) */
    uint16 chunk_off;       /* 本片在完整数据区中的偏移 */
    uint16 chunk_len;       /* 本片 chunk 字节数 */
    uint8  chunk[chunk_len];
} sIOCtrl2WCS_PortState_Seg;

  WCS 须收齐同周期全部片后拼接、校验 body_crc，再按 4.1(3) 单帧格式解析。
  单片数据区 ≤256 字节；chunk 最大 244 字节。

（4）应答帧命令：0x9402

（5）应答数据区：仅 cmd[11]


4.2  下料口上线命令（0x1403）

（1）发送时间：主机与 WCS 建链成功后主动发送。

（2）发送帧命令：0x1403

（3）数据格式
typedef struct { uint8 cmd[11]; } sIOCtrl2WCS_Online_Data;

（4）应答帧命令：0x9403（交叉带规定 WCS 回传 ioCtrl_num）

（5）V5 说明
  从机数量 ioCtrl_num 仅由 0x1423.slave_num 决定；主机不解析 0x9403 载荷覆盖计数。
  交叉带 WCS 仍可应答 0x9403，但 V5 主机以 1423 为准。


4.3  下料口打印命令（0x1404）

（1）发送时间：打印键有效边沿触发时主机主动发送（同一按键长按不重复上报）。

（2）发送帧命令：0x1404

（3）数据格式
typedef struct
{
    uint8  cmd[11];
    uint16 print_addr_num;
    uint16 print_addr[print_addr_num];
} sIOPrt2WCS_Print_Data;

（4）应答帧命令：0x9404

（5）应答数据区：print_addr_num + print_addr[]（打印完成确认，格式同发送）


4.4  SCADA 关闭滑槽口（0x1405）

（1）发送时间：WCS 关格/开格时立即发送。

（2）发送帧命令：0x1405

（3）数据格式
typedef struct
{
    uint8  cmd[11];
    uint8  close_cmd;
    uint16 close_addr_num;
    uint16 close_addr[close_addr_num];
} sWCS2IOCtrl_Close_Data;

变量类型    变量名          含义
uint8       close_cmd       0=关格（远程锁格）  1=开格（解除远程锁）
                            2～13 交叉带扩展命令本固件未实现
uint16      close_addr_num  格口数量
uint16      close_addr[]    格口地址（须在 1424 范围内）

（4）应答帧命令：0x9405

（5）应答数据区：仅 cmd[11]


4.5  清空下料口命令（0x1406）

（1）发送时间：WCS 下发清空时。

（2）发送帧命令：0x1406

（3）数据格式
typedef struct
{
    uint8  cmd[11];
    uint16 clear_addr_num;
    uint16 clear_addr[clear_addr_num];
} sWCS2IOCtrl_Clear_Data;

（4）应答帧命令：0x9406


4.6  下料口系统版本信息（0x140B）

（1）发送时间：上电后短时内发送约 3 次。

（2）发送帧命令：0x140B

（3）数据格式
typedef struct
{
    uint8 cmd[11];
    uint8 version[4];    /* 小端，例 5.1.7.1 → 0x01,0x07,0x01,0x05 */
} sIOCtrl2WCS_Version_Data;

（4）应答：无需应答


4.7  从板 CAN 通讯报警（0x1413）

（1）发送时间：约每 5s 检测；仅有异常从站时发送，无异常不发（避免 num=0 空包）。

（2）发送帧命令：0x1413

（3）数据格式
typedef struct
{
    uint8 cmd[11];
    uint8 num;
    uint8 station[num];   /* CAN 通讯异常（COS 超时）的从站站号 */
} sIOCtrl2WCS_CanError_Data;

  判定：从站曾上报 COS CONFIRM，且超过 stale 时间未再收到（见 6.2）。


4.8  子模块版本校验（0x142C）

（1）发送时间：上电/建链时；未收到 WCS 应答则约 10s 周期重发。

（2）发送帧命令：0x142C

（3）数据格式
typedef struct
{
    uint8  cmd[11];
    uint8  submodule_type;      /* 下料口控制器 = 3 */
    uint16 version_strlen;
    char   version[version_strlen];
} sIOCtrl2WCS_ValidateVer_Data;

  当前 version 字符串：chute_5.1.7.1_w16_261014

（4）应答帧命令：0x942C（仅 cmd[11]）


================================================================================
5  V5 配置扩展命令
================================================================================

5.1  转发下料口屏幕数据（0x1422）

（1）发送时间：初始化或显示内容变化时，WCS → 主机。

（2）发送帧命令：0x1422

（3）数据格式
typedef struct
{
    uint8  cmd[11];
    uint8  total_num;       /* ≤20 */
    struct {
        uint16 port_io;     /* 格口地址（同 1402） */
        uint8  type;        /* 1格口 2入袋件数 3流向 4目的地 */
        uint8  total_len;
        uint8  scr_buf[total_len];
    } data[total_num];
} sWCS2IO_Screen_Data;

（4）应答帧命令：0x9422


5.2  初始化拓扑配置（0x1423）

（1）发送时间：上电建链必须；改拓扑时重发。

（2）发送帧命令：0x1423

（3）数据格式
typedef struct
{
    uint8  cmd[11];
    uint8  slave_num;       /* 从站总数，刷新 ioCtrl_num */
    uint8  group_total;     /* 组数 ≤20；0=无分组策略 */
    uint8  expand_master;   /* 0主板 1上层扩展主板 */
    struct {
        uint8  each_total;  /* 本组站数 ≤20 */
        struct {
            uint8 station;      /* 站号 ≥2 */
            uint8 block_group;  /* 卡包组号，通常 1 或 2 */
        } each[each_total];
    } group[group_total];
} sWCS2IO_Init_Config;

  group_total=0 且 slave_num>0：自动生成站号 2..(slave_num+1)，等价连续赋号。
  单机单从可发 slave_num=1, group_total=0。

（4）应答帧命令：0x9423


5.3  初始化格口地址范围（0x1424）

（1）发送时间：与 1423/1425/1426 一并构成就绪四件套。

（2）发送帧命令：0x1424

（3）数据格式
typedef struct
{
    uint8  cmd[11];
    uint16 ip_offset_start;   /* 含；字段名沿用历史拼写 offest */
    uint16 ip_offset_end;     /* 含 */
} sWCS2IO_IpOffset_Data;

  本命令不创建格口；真正映射由 1426.port_map 建立。

（4）应答帧命令：0x9424


5.4  初始化滤波时间（0x1425）

（1）发送时间：建链或调参。

（2）发送帧命令：0x1425

（3）数据格式
typedef struct
{
    uint8  cmd[11];
    uint16 time_num;              /* 须 ≥5 */
    uint16 lock_filter_time;      /* 锁格键，ms */
    uint16 full_filter_time;      /* 满包，ms */
    uint16 block_filter_time;     /* 夹件，ms */
    uint16 door_filter_time;      /* 门磁，ms */
    uint16 print_filter_time;     /* 打印键（固件字段 solt_filter_time），ms */
} sWCS2IO_Init_Time_Data;

  从站对物理脚去抖后上报 COS CONFIRM；主机对 CONFIRM 直写电平不再二次滤波。
  同一套时间作用于从站脚滤波与主机业务逻辑，现场按总延时理解。

（4）应答帧命令：0x9425


5.5  物理脚绑定配置（0x1426）【核心】

（1）发送时间：首次接线、改脚位、改格口映射时。可分包发送。

（2）发送帧命令：0x1426

（3）分段帧头（每片相同）
typedef struct
{
    uint8  cmd[11];
    uint16 field0;       /* 2=format2(推荐)；其它正整数=format1 记录条数 */
    uint16 ver;
    uint16 crc;          /* 整包 CRC16-CCITT，对拼接后 blob 计算（不含本片头） */
    uint16 seg_total;
    uint16 seg_index;    /* 从 0 连续递增 */
    uint16 seg_bytes;
    uint8  seg_data[seg_bytes];
} sWCS2IO_Pin_SegHdr;

（3b）format2 整包 blob 布局（推荐）
  board_count          uint8
  对每块从站重复：
    station            uint8
    local_port_count   uint8    /* 1～8 */
    in_cnt, out_cnt    uint8
    flags              uint16   /* bit0=接近开关mux  bit1=偶数喷码OR IN5满包 */
    print_after_lock_ms uint16
    jam_fanout_count   uint8    /* ≤12 */
    port_map[lpc]      uint16[] /* 各本地口对应格口地址 */
    in_bind[in_cnt]    每条 4B：pin, func, local_port, flags
    out_bind[out_cnt]  每条 4B：pin, func, local_port, flags
    jam_fanout[]       uint16[] /* 夹件连带格口地址（绝对地址） */

  单条绑定 flags：bit0=低有效；bit1=OR（多脚合成同一输入角色）
  local_port=0xFF 表示板级绑定（夹件 IN 或公共 OUT）

（3c）format1（定长记录，兼容旧工具）
  field0=N 条记录，每条 27 字节（含 OR 掩码）或 24 字节（无 OR，主机补 0）

（4）应答帧命令：0x9426
typedef struct
{
    uint8 cmd[11];
    uint8 result;   /* 0成功 2参数 3序号 4溢出 5CRC/解析 */
} sWCS2IO_Pin_Ack;

  中间片不应答；收齐成功或失败均应答。
  成功后会热切换运行表并重推 PIN；按格口地址保留 0x1405 关格状态。

（5）校验规则
  · station 须在 1423 拓扑内；port_map 格口地址全机唯一（允许为 0，与现场 WCS 点位从 0 起一致）
  · board_count ≤96；Σ local_port_count ≤128（或编译档 256）


5.6  灯效配置（0x1428）

（1）发送时间：需要按钮灯/塔灯/蜂鸣时推荐发送；未发则「有 1402、灯全灭」为预期。

（2）发送帧命令：0x1428

（3）数据格式
typedef struct
{
    uint8 cmd[11];
    uint8 func;    /* 1=组合规则(推荐)  2=仅矩阵(等同旧 0x1427) */
    /* func=1：16B 头 + rule_count×10B 规则 + CRC16 */
    /* func=2：16B 头 + 48B 矩阵 + CRC16 */
} sWCS2IO_Logic_Data;

  组合规则头（16 字节）字段：
    profile_ver, button_mode, lock_print_mode, print_gate, cond_priority,
    report_flags, rule_count, flash_fast_ms, flash_slow_ms,
    print_delay_ms, release_filter_ms

  单条规则（10 字节）：out_ch, mode, prio, reserved, and_mask, or_mask, not_mask
    out_ch：逻辑通道 0～5
    mode：0关 1开 2快闪 3慢闪
    信号位 and/or/not：bit0锁 bit1打印 bit2满包 bit3半满 bit4夹件 bit5关格(1405)

  report_flags：bit0 等同 142F 半满扩展；bit2 满包档扩展

（4）应答帧命令：0x9428

  禁止新上位机单独发 0x1427；请统一使用 0x1428 func=2 更新矩阵。


5.7  主机未就绪上报（0x1429）

（1）发送时间：未满足 1.4 就绪条件时，约每秒 1 次。

（2）发送帧命令：0x1429

（3）数据格式
typedef struct
{
    uint8 cmd[11];
    uint8 missing_flags;   /* bit0=缺1423 bit1=缺1424 bit2=缺1425 bit3=缺1426；1=仍缺 */
} sIOCtrl2WCS_ConfLose_Data;

  交叉带 5.33 无 missing_flags 字节；V5 须解析此字段决定补发哪些配置。

（4）应答：可不应答


5.8  从站配置失败上报（0x142A）

（1）发送时间：已就绪，但从站 PIN 异常或主机 Flash 自动保存失败时，约每秒 1 次。

（2）发送帧命令：0x142A

  交叉带 5.34 为打印触发；V5 语义完全不同，勿混用。

（3）数据格式
typedef struct
{
    uint8 cmd[11];
    uint8 num;
    struct {
        uint8 station;
        uint8 reason;
    } item[num];
} sIOCtrl2WCS_SlaveCfgFail_Data;

  reason 取值：
    1=超时  2=CRC  3=Flash  4=分段  5=参数  6=无PIN  7=拓扑外孤儿站
    8～15=主机 Flash 保存失败（station=0）：
      8未细分 9未ready 10样板站号<2 11打包失败 12堆不足
      13擦写失败 14读回校验失败 15异类站超8或失败

（4）应答：可不应答


5.9  急停转发（0x142B）

（1）发送时间：急停状态变化时；可约 10s 周期保活。

（2）发送帧命令：0x142B

（3）数据格式
typedef struct
{
    uint8 cmd[11];
    uint8 emergency_state;   /* 0正常  1急停 */
} sWCS2IO_Emergency_Data;

  主机经 CAN 广播至从站，从站全口锁格。

（4）应答帧命令：0x942B


5.10  本地模板固化（0x142D）

（1）发送时间：现场验证通过后可选执行，实现掉电保持。

（2）发送帧命令：0x142D

（3）数据格式
typedef struct
{
    uint8 cmd[11];
    uint8 op;
    uint8 arg;    /* 站号或 0xFF */
} sWCS2IO_CfgStore_Data;

  op：1=保存样板  2=保存异类  3=清除异类(arg=0xFF清全部)
      4=从 Flash 展开应用  5=清除模板

  异类站最多 8 个；超过请每次上电下发完整 1426。

（4）应答帧命令：0x942D


5.11  夹件连带列表编辑（0x142E）

（1）发送时间：运行中修改连带关系，无需重发整包 1426。

（2）发送帧命令：0x142E

（3）数据格式
typedef struct
{
    uint8  cmd[11];
    uint8  station;
    uint8  op;           /* 1替换 2追加 3删除 4清空 */
    uint8  count;
    uint16 port_addr[count];   /* 绝对格口地址 */
} sWCS2IO_JamFanout_Data;

（4）应答帧命令：0x942E


5.12  上报扩展与跨站 OUT（0x142F）

（1）发送时间：需要半满/满包档独立上报，或塔灯跨站镜像时。

（2）发送帧命令：0x142F

（3）数据格式
  upload_flags  uint16
  xout_count    uint8   /* ≤16 */
  重复 xout_count 次：
    target_station, target_pin, src_ch, flags

  upload_flags：bit0=1402 追加半满组；bit2=追加满包档1/档2组

（4）应答帧命令：0x942F


5.13  拓扑从机就位状态（0x1430）【V5 联调专用】

（1）发送时间
  主机已就绪、无 142A、且拓扑内仍有从站 flags≠0x03 时：
  须连续 3 次（每秒检测）未全就位后才开始周期上报；中途恢复则计数清零。
  全站 flags=0x03 后停止发送。
  运行期判断下料口在线请以 0x1402 为准，勿依赖本命令。

（2）发送帧命令：0x1430

（3）数据格式
typedef struct
{
    uint8 cmd[11];
    uint8 num;
    struct {
        uint8 station;
        uint8 flags;    /* bit0=PIN配置成功  bit1=COS在线；0x03=就位 */
    } item[num];
} sIOCtrl2WCS_SlaveReady_Data;

（4）应答：可不应答


5.14  触发站号自学习（0x1431）

（1）发送时间：拨码为 00 的从机需链式赋号时，在 1426 之前由 WCS 显式触发。
  上电、收 1423、Flash 恢复均不会自动学习。

（2）发送帧命令：0x1431

（3）数据格式
typedef struct
{
    uint8 cmd[11];
    uint8 op;    /* 1=启动学习 */
} sWCS2IO_StationLearn_Data;

（4）应答帧命令：0x9431
typedef struct
{
    uint8 cmd[11];
    uint8 result;   /* 0已启动 1参数 2无拓扑 3学习进行中 */
} sWCS2IO_StationLearn_Ack;

  学习进行中主机暂停 PIN 下发；完成后若已就绪自动继续分发。


5.15  站号学习完成（0x1432）

（1）发送时间：1431 触发的学习全部结束后，主机主动上报一次。

（2）发送帧命令：0x1432

（3）数据格式
typedef struct
{
    uint8 cmd[11];
    uint8 summary;    /* 0=全部成功  1=至少一站失败 */
    uint8 num;
    struct {
        uint8 station;
        uint8 result;   /* 0=该站成功  1=超时 */
    } item[num];
} sIOCtrl2WCS_StationLearnDone_Data;

（4）应答：可不应答


================================================================================
6  主机内部机制（CAN / COS）
================================================================================

  本章供理解 0x1402 / 0x1413 / 0x1430 的数据来源；WCS 无需直接组 CAN 帧。

6.1  配置下发（主机 → 从站）

  CAN func_id    含义
  ─────────────────────────────────────────
  0x7            FUNC 角色
  0x8            TIME（5×uint16 + CRC16，12 字节）
  0xE            PIN 站切片
  0x12           站号自学习（1431 触发）
  0x2            PORT_STATE 下行（关格命令 + 慢同步）

6.2  状态上报（从站 → 主机，COS 握手）

  从站对物理 DI 经 1425 时间去抖后，通过 COS 两阶段上报：

  func_id    名称        说明
  ─────────────────────────────────────────────────────────
  0x10       TRIG        变化后短防抖 15ms 发送；主机仅用于灯效预提示
  0x11       CONF        稳定保持 25ms 后发送；主机据此更新 0x1402

  8 字节载荷布局（Data[0]～Data[7]）：
    [0]半满 [1]满包 [2]夹件 [3]门 [4]锁格 [5]打印 [6]满包档1 [7]满包档2
  每字节为本地口位图（bit0～bit7 对应 local_port 0～7）。
  序号 seq 在 CAN 扩展帧 ExtID.seg_num，不在 Data[0]。

  主机每 500ms 对拓扑内各站发送 PORT_STATE 且 data[0]|=0x80（同步标志），
  从站须优先回 CONF（即使同时有打印状态帧，也不得阻塞 CONF）。

  stale 判定：超过 max(500ms, 站数×500ms×4) 未收到某站 CONF，则该站格口
  不参与 0x1402 组包，并可能触发 0x1413 / 0x1430 flags 缺 bit1。

6.3  1430 flags 含义

  bit0  PIN 配置成功（从站 ACK 且主机认为该站 PIN 有效）
  bit1  COS 在线（曾收到 CONF 且未 stale）
  0x03  = 该站就位


================================================================================
7  推荐上线流程
================================================================================

7.1  拨码已固定站号（常见）

  1) 0x1423 拓扑
  2) 0x1424 格口地址范围
  3) 0x1425 滤波时间
  4) 0x1426 脚位绑定（检查 0x9426 result=0）
  5) 0x1428 灯效（需要灯时）
  6) 可选 0x142F 扩展上报
  7) 验证 0x1402 / 0x1404 / 0x1405
  8) 可选 0x142D 固化 → 断电复测

7.2  含拨码 00 需链式赋号

  1) 0x1423
  2) 0x1431 op=1 → 等待 0x1432 summary=0
  3) 轮询至 0x1430 全站 flags=0x03（或跳过，直接发 1424～1426 后观察 1402）
  4) 0x1424 → 0x1425 → 0x1426 → 0x1428 …

7.3  诊断

  收到 0x1429：按 missing_flags 补发 1423～1426
  收到 0x142A：按 station/reason 查从站 PIN 或 Flash
  收到 0x1413：查 CAN 接线、从站供电、COS 版本是否与主机一致
  运行期无 1402：查网络、主机是否 ready、WCS 是否解析 Pause 组导致误判
